# 5월 8일 실무 역량 강화 실습
# 스마트 창고 및 재고 발주 관리 시스템

## 1. 과제 목표

Java MVC 패턴과 CSV 파일 입출력을 활용하여  
창고 물품의 재고를 관리하는 콘솔 프로그램을 구현한다.

이번 과제는 메뉴 관리 프로그램을 응용하여  
단순 CRUD뿐 아니라 재고 입고, 출고, 재고 부족 알림, 총 자산 계산 기능까지 연습한다.

---

## 2. 구현할 프로그램

프로그램 이름: 스마트 창고 및 재고 관리 시스템

관리 대상: 창고 물품

물품 정보는 다음 항목을 가진다.

| 항목    | 변수명       | 타입     | 설명             |
|-------|-----------|--------|----------------|
| 물품 코드 | productId | String | 물품 고유 번호       |
| 물품명   | name      | String | 물품 이름          |
| 단가    | price     | int    | 물품 1개의 가격      |
| 현재 재고 | stock     | int    | 현재 보유 수량       |
| 안전 재고 | minStock  | int    | 최소로 유지해야 하는 수량 |
| 카테고리  | category  | String | 물품 분류          |

---

## 3. 필수 구현 기능

### 1. 물품 등록

새로운 물품 정보를 등록한다.

입력 항목:

- 물품 코드
- 물품명
- 단가
- 현재 재고
- 안전 재고
- 카테고리

주의사항:

- 이미 존재하는 물품 코드는 등록할 수 없다.
- 물품 코드는 `equals()` 기준으로 비교한다.

---

### 2. 물품 삭제

물품 코드를 입력받아 해당 물품을 삭제한다.

주의사항:

- 존재하지 않는 물품 코드를 입력하면 예외 메시지를 출력한다.

---

### 3. 물품 수정

물품 코드를 입력받아 기존 물품 정보를 수정한다.

수정 가능 항목:

- 물품명
- 단가
- 현재 재고
- 안전 재고
- 카테고리

---

### 4. 전체 물품 조회

현재 등록된 전체 물품 목록을 출력한다.

---

### 5. 물품 입고

물품 코드를 입력받고, 입고 수량을 입력받는다.

기존 재고에 입고 수량을 더한다.

예시:

```text
현재 재고: 10
입고 수량: 5
변경 후 재고: 15
